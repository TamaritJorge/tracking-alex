# Tracking Álex

Una libreta para el día a día de un bebé: pañales, peso, extracción de
leche, medicinas y alimentación complementaria, con las curvas de la OMS.
Sin publicidad, sin rastreadores y sin vender datos.

**https://trackingalex.app**

## Por qué está aquí a la vista

Esto trata con datos de niños, así que el código está público para que se
pueda comprobar lo que hace. Si algo de lo de arriba te parece una promesa
fácil, léelo y júzgalo tú.

Público no es lo mismo que libre: no lleva una licencia de código abierto.
Se puede leer, auditar y aprender de él; no copiar ni republicar. Está
explicado en [LICENSE](LICENSE), y para cualquier otra cosa basta con
preguntar: info@trackingalex.app

Si encuentras un fallo —y más si es de seguridad— se agradece el aviso.
